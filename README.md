# Dataset Collection and Data Processing

This repository contains the dataset collected and prepared for the project. It documents the complete data preparation process, from collecting the initial data to cleaning, transforming, and organizing it for use in the final system.

## Contents

* **Raw Dataset** – Initially collected data used as the source for the project.
* **Processed Dataset** – Cleaned and structured data after preprocessing.
* **Data Processing** – Scripts and notebooks used for cleaning, transformation, formatting, and preparation of the dataset.
* **Documentation** – Details of the dataset and the preprocessing steps performed.

## Data Processing

The collected data was processed to improve its consistency and suitability for the project. The processing includes data cleaning, removal of unnecessary or duplicate information, handling of missing or inconsistent values, and restructuring of the data into a suitable format.

## Purpose

The prepared dataset serves as the data source for the project's subsequent development and evaluation. This repository is maintained separately to keep the dataset collection and preprocessing workflow organized and reproducible.

## Project

This repository is part of the data preparation phase of the project and supports the development of the main system.
